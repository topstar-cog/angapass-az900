# AngaPass: AZ-900 Study Coach (Unofficial)

*Your sky-high shortcut to AZ-900.* ("Anga" is Swahili for "sky".)

Smart Quiz Builder + Readiness Tracker for the Microsoft Azure Fundamentals (AZ-900) exam.
Built for the Vibe Coding Hackathon, 1 Million Devs.

**Unofficial study tool. Not affiliated with or endorsed by Microsoft.**

## Features
- 96 original practice questions across the three AZ-900 domains
- Learn mode with instant feedback, and an explanation of why each option is right or wrong
- Timed mock exam with a mistakes review
- Weak-spot mode that replays questions you got wrong
- Readiness dashboard weighted by AZ-900 exam domains

## How it was built
- Plain HTML, CSS and JavaScript in one file, with progress saved in the browser
- All questions are original, written from my own AZ-900 study guide and the public skills outline on Microsoft Learn
- Built with help from Claude (prompt-driven design and question writing)

## Run it
Open `index.html` in any browser.
